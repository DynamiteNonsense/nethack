# Сборка исходного NetHack 5.0.0 в Windows x64

**Эта инструкция собирает оригинальную английскую игру. Русификации в комплекте пока нет.**
Основана на `sys/windows/build-msys2.txt` и проверке `sys/windows/GNUmakefile` данного релиза. Здесь сборка на Windows не запускалась. ARM64, x86, WSL и другие окружения этим сценарием не проверяются.

## Подготовка

Установите MSYS2 с https://www.msys2.org/ и обновите по инструкции MSYS2. Используйте именно окно **MSYS2 UCRT64**, а не MSYS, MINGW32 или PowerShell для команд сборки.

В UCRT64 установите инструменты:

````sh
pacman -S --needed mingw-w64-ucrt-x86_64-toolchain make curl tar
````

Распакуйте исходники, например в `C:\dev\nethack-ru`. Для первого запуска рекомендуется путь без пробелов и кириллицы: это упрощает диагностику и не является гарантией поддержки или неподдержки других путей.

## Запуск сценария

Из корня исходников, где находятся `src`, `include`, `sys` и `ru-project`:

````sh
cd /c/dev/nethack-ru
bash ru-project/build-windows-ucrt64.sh
````

Сценарий загружает исходники Lua 5.4.8 с официального сайта по HTTPS, если их ещё нет. Сам Lua не входит в приложенный архив. Для скачивания нужен интернет на вашем компьютере. Сценарий копирует штатные GNUmakefile в `src` и запускает терминальную сборку.

Используется цель `binary` с `SKIP_NETHACKW=Y`, а не цель `package`: список файлов `package` в этом релизе содержит также графический `NetHackW.exe`. Это позволяет не требовать графическую сборку для вашей задачи. При отсутствии PDCursesMod компилируется штатный TTY; устанавливать PDCursesMod для этой базовой проверки не требуется.

В качестве защиты от неявных скачиваний Makefile получает `INTERNET_AVAILABLE=N` после отдельной загрузки Lua. Контрольная сумма Lua в сценарии не закреплена; для воспроизводимого выпуска нужно отдельно проверить официальный архив и закрепить хеш.

## Запуск игры

Ожидаемый результат успешной сборки находится в каталоге `binary`. В Windows Terminal откройте PowerShell, перейдите в этот каталог и запустите:

````powershell
cd C:\dev\nethack-ru\binary
.\NetHack.exe
````

Не переносите один `.exe` без сопутствующих файлов: игра использует файлы данных и, при штатных настройках этой сборки, DLL Lua.

Проверьте создание героя, начало партии, инвентарь, сохранение и восстановление. Пользуйтесь тестовой партией, не единственной копией важного сохранения. Отчёт об ошибке должен содержать вывод команды сборки и первую ошибку компилятора.

## Что эта сборка НЕ проверяет

Русский текст ещё не добавлен. `chcp 65001`, выбор шрифта или успешный запуск английской игры сами по себе не доказывают правильность UTF-8, русских имён, переносов и удаления символов. Для будущей локализации эти проверки обязательны отдельно.
