# NetHack 5.0.0: русская версия, предварительный патч 0.1

**Это частичная экспериментальная русификация, не полный перевод игры.**
Цель этой версии: проверить реальный двуязычный вывод в Windows TTY и получить небольшую работающую основу для дальнейшего перевода. Основа: официальный тег `NetHack-5.0.0_Released`, commit `16ff59115315917b93185d026aeefea06db9b0f4`.

Дата изменений: 2026-09-09. Изменённая версия не является официальным выпуском команды NetHack. Код и переводы распространяются на условиях NetHack General Public License, без гарантий; полный текст находится в `dat/license` и в `LICENSE` пакета обновления.

## Что реализовано

В каталоге 285 точных игровых сообщений и 3 новых диагностических сообщения. Переведены выбранные сообщения о дверях, движении, еде, экипировке, зельях, свитках и состоянии персонажа. Например:

> Вы не видите там двери. (You see no door there.)
>
> Эта дверь заперта. (This door is locked.)
>
> Вы чувствуете себя лучше. (You feel better.)

Русский текст добавляется только при отображении строки сообщений. Внутренние английские сообщения остаются оригинальными. Русский перевод не подставляется в имена предметов, обработчик желаний, фильтры сообщений или сохраняемые структуры героя.

Поддерживаемые символы каталога: ASCII, русские буквы А-Я/а-я, Ё/ё. Они декодируются из UTF-8 и выводятся как отдельные кодовые точки через существующий Unicode-путь Windows TTY. Перенос выполняется по экранным позициям; длинная пара RU (EN) не складывается в старый фиксированный буфер сообщений. Отдельные английские сообщения в каталоге короче предела ядра; обрезка произвольных остальных сообщений ядром в этой версии не переделана.

Также исправлено повторное присваивание `NHV=370` в Windows GNUmakefile и имя архива в списке упаковки. Для терминальной сборки по-прежнему используется цель `binary`, чтобы не требовать графический `.exe`.

## Что ещё НЕ реализовано

Это не перевод всех меню, инвентаря, названий предметов и существ, заданий, энциклопедии и справки. Динамические сообщения с именами существ и предметов в основном остаются английскими. Совпадение с каталогом должно быть точным; изменённые префиксы доступности, сообщения во сне и иные варианты могут остаться английскими.

Полноэкранное меню истории сообщений пока остаётся английским: в истории хранятся оригиналы. Однострочный повтор через путь `putsyms` может отображать перевод. Подсказки клавиш, строка состояния, `--More--` и вопросы с добавленными вариантами ответа ещё не локализованы.

Ввод и редактирование русских имён, русские команды и желания пока НЕ исправлены. Используйте латинское имя тестового персонажа. Этот патч не означает полной Unicode-поддержки игры и не рассчитан на произвольные эмодзи, диакритику или широкие азиатские символы. Целевая среда: Windows 10/11 x64, MSYS2 UCRT64, TTY, обычная сборка без `NO_VT`.

## Обновление уже собранных исходников

Сначала закройте игру. Сохраните контрольную копию работающей папки `binary` вне каталога сборки. Сохранения могут лежать в пользовательском каталоге Windows: их путь можно узнать через `NetHack.exe --showpaths`. Установщик не ищет и не удаляет сохранения, но это не заменяет вашу резервную копию.

Распакуйте маленький пакет обновления, например в `D:\games\nethack-ru-preview-0.1-patch`. В MSYS2 UCRT64 выполните:

````bash
cd /d/games/nethack-ru-preview-0.1-patch
bash apply.sh /d/games/NetHack
````

Установщик проверяет контрольные суммы всех обновляемых файлов до изменений и отказывается затирать неизвестные правки. В `ru-project` целевого проекта создаётся резервная папка с изменяемыми файлами. Повторное применение того же пакета допустимо. Ручная правка только прежнего `ru-project/build-windows-ucrt64.sh` не мешает: этот сценарий не заменяется.

После успешного применения:

````bash
cd /d/games/NetHack
bash ru-project/build-ru-preview.sh
````

Сценарий сначала компилирует и запускает отдельные C-тесты того же заголовочного файла, который использует игра. Проверяются декодирование Ё/ё, кириллицы, отказоустойчивость на оборванных последовательностях, поиск сообщений, точность английского суффикса, переносы на разных ширинах и отключение перевода.

Затем выполняется инкрементальная сборка с `NHV=500` и проверяется существование `binary/nhdat500`. `make clean` автоматически не выполняется. Исходники Lua повторно не скачиваются, если уже находятся в штатном каталоге.

## Если скачан полный архив исходников

Распакуйте его в отдельный каталог. В MSYS2 UCRT64 при необходимости установите `mingw-w64-ucrt-x86_64-toolchain`, `make`, `curl`, `tar` и запустите из корня `bash ru-project/build-ru-preview.sh`. Сценарий загрузит Lua 5.4.8 с официального сайта по HTTPS, если исходников Lua ещё нет. Они не входят в архив. Хеш архива Lua пока не закреплён в сценарии.

## Первая проверка в игре

В CMD, из нового `binary`:

````bat
cd /d D:\games\NetHack\binary
set NETHACK_RU=1
set NETHACK_RU_TEST=1
NetHack.exe -u RuPreview01
````

Для первого теста выбирайте новое имя, чтобы не возвращаться к проблеме несовместимого `wizard.NetHack-saved-game`. Не запускайте одновременно несколько копий игры.

После создания героя появятся три диагностические фразы. Это новые тестовые сообщения, а не строки оригинальной игры. Первая должна содержать:

> Проверка кириллицы: ёж, щука, съешь ещё. (Cyrillic test: hedgehog, pike, eat some more.)

У длинного сообщения проверьте перенос и полное окончание английской части. При `--More--` нажимайте пробел. Проверьте ширину окна 80, 120 и 160 колонок, затем обычные сообщения у двери. Вывод должен оставаться читаемым, без потерянных букв и наложений на карту. Проверьте сохранение тестовой партии и её повторную загрузку.

После выхода отключите только диагностические сообщения:

````bat
set NETHACK_RU_TEST=
````

Для возврата к английскому отображению без пересборки, в этом же окне CMD:

````bat
set NETHACK_RU=0
NetHack.exe -u RuPreview01
````

Чтобы снова включить русский вывод, задайте `set NETHACK_RU=1`. По умолчанию, если переменная не задана, перевод включён. Настройки через `set` действуют в текущем CMD и запускаемых из него процессах.

## Статус проверки

В среде подготовки выполнены проверки UTF-8-каталога, точности сгенерированного английского суффикса, воспроизводимости генератора, синтаксиса Bash и независимой Python-модели переноса. Проверено, что из 1265 оригинальных файлов изменены только 3: `win/tty/topl.c`, `sys/windows/windmain.c`, `sys/windows/GNUmakefile`. Добавлены каталог, заголовок, тесты и служебные файлы. Структуры сохранений и глобальные размеры буферов не изменялись.

**Компиляция C, Windows-сборка и запуск в Windows Terminal в среде подготовки не выполнялись.** C-тесты включены в вашу команду сборки. Успех этих тестов не заменяет игровую проверку в терминале. Машинно-читаемый отчёт: `VALIDATION_PREVIEW.json`.

Если сборка остановится, пришлите первую ошибку и конец вывода. Если проблема визуальная, пришлите снимок экрана с целой строкой RU (EN) и размер окна. Не отключайте проверки совместимости сохранений.

## Редактирование переводов

Человекочитаемый каталог: `ru-project/messages.ru.json`. В каждой записи сохранены английская строка, русский перевод и ссылки на места в исходниках. Заголовок C содержит UTF-8 в восьмеричных байтовых последовательностях, поэтому не зависит от кодировки исходного файла компилятора.

Если установлен Python 3, после редактирования каталога выполните `python ru-project/generate_messages.py` и снова запустите `bash ru-project/build-ru-preview.sh`. Python не нужен для обычной сборки уже подготовленного патча. Заголовок включён в зависимости `topl.o`.
